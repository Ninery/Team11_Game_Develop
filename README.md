# Cat-astrophe

A 2D pixel-art stealth puzzle game developed as a group project in Unity.

The player takes the role of an office worker trying to return home during a monster outbreak. Along the way, the player must explore different areas, solve puzzles, avoid monsters and collect cats in order to achieve the best ending.

## Game Features

* 2D pixel-art visual style
* Stealth-based gameplay
* Puzzle solving
* Monster chase sequences
* Item collection and inventory
* Cat collection system
* Multiple endings
* Environmental interactions
* Keyboard and mouse controls
* WebGL playable build

## Controls

| Input         | Action                |
| ------------- | --------------------- |
| A / D         | Move                  |
| E             | Interact / Collect    |
| Mouse         | Interact with puzzles |
